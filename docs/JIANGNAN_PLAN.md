## 这次迭代要交付什么

观众从南岸看向水榭，应能顺着屋檐和柱影看清整座院子的布局；走近后，通过湿石、窗后的疏竹和收敛的水纹读出“雨刚停”。压低机位看倒影，抬高机位看浅岸石阶的折射。总览图负责交代地点和天气，技术对照图负责说明这些水面效果怎样形成。

## 开发顺序

以下工时是本轮建议的团队人时，不含可选项和等待演示机的时间。按 A → B → C → D 推进，预计 **26–40 人时**。负责人按工作包认领。每阶段交付可复现的画面与参数，达到验收条件后独立提交至 GitHub。

| 阶段／牵头 | 实施与依赖 | 交付与通过条件 |
| --- | --- | --- |
| **A 空间灰模** · 场景建模 · 8–12 人时 | 先在旧版本固定总览和掠射机位截图。改造 `src/main.cpp` 的 `courtyard()`、`banks()`、`submerged()`：搭水榭台基、柱础、栏杆、檐口和瓦脊；接短廊或回折墙，留出两到三种有节奏的贯通窗洞；做厚池沿、错缝和浅阶。 | 交总览与低机位灰模图。池面约占总览下半部，中央倒影区开阔；移动机位能透窗看到后景。零振幅时柱影贴合，近岸深度图没有空白边带。先调整轮廓和遮挡，再加细节。 |
| **B 材质与近景** · 场景美术 · 7–10 人时 | 在 A 定稿的尺度上做灰瓦、暗木、水迹粉墙、错缝青石及由岸向外渐干的铺地。换掉满池方格，只在浅阶或沉石保留折射参照；在墙后布置疏竹，岸边加一株斜枝树和少量石景。程序化变化使用固定参数或种子。 | 交总览、俯视和池边近景。远景先读出水榭和倒影；近景能区分湿石与水面，窗后有层次。浅区石纹可辨，深区无重复棋盘格，枝叶不遮住中央水面。 |
| **C 水与光联调** · 水面与渲染 · 6–10 人时 | B 的明暗关系稳定后，联调场景天光、`src/water.h` 的初始振幅与 `src/water.cpp` 的细波、高光、吸收和透射底色。用零振幅校准，再以较低振幅试拍；冻结动画，只改一个参数做对照。 | 交全效果、关倒影、关折射扰动、固定 Fresnel 权重四帧。低机位仍能追踪屋檐与柱影，俯视浅岸有折射、深处仍有层次；沿岸移动时无缝隙闪烁。另以零吸收与默认吸收做诊断，核对深度变化。 |
| **D 演示与复现** · 集成评估 · 5–8 人时 | 锁定四机位、主题振幅、时间、光照和渲染尺寸；整理 PNG、参数与命令，更新 README 和实验报告。核对设计参考、课程取舍与资产来源。 | 另一成员按说明从空目录构建，在演示机复现四帧对照，试用漫游、波浪和效果开关。记录硬件、驱动、垂直同步、可见窗口 FPS 和三段渲染耗时；画面与性能同时通过后交付。 |

## 三处容易返工的接点

1. **水线两侧要看见同一段岸。** 现有反射通道用镜像视图绘制 `courtyard()`，水下通道裁剪后绘制 `banks()` 和 `submerged()`。新增墙窗、屋檐和竹子须进主场景与反射；跨过水线的池沿或台基须让水下部分写入折射颜色与深度。A 就用 `edge` 机位检查，避免重现旧版池壁亮带。
2. **分别检查波形、高光和水色。** 当前振幅同时影响几何波和细法线，直接降到极低会使折射对照也难辨。先定低机位的柱影，再到俯视检查浅阶石纹；必要时分调细法线和高光。现有 `depth` 模式显示水中路径长度；吸收对照用相同条件下两档吸收强度，不能用灰度调试图代替。
3. **把机位和测量条件写进报告。** 现有四机位名为 `default`、`grazing`、`top`、`edge`。技术四帧统一用 `default`、1280 × 720、同一振幅和 1 秒，模式分别为 `full`、`no-reflection`、`no-distortion`、`fixed-blend`。额外角度用于看构图和边界。沿用 `--benchmark` 测反射、折射、最终场景，并单独测可见窗口；旧场景隐藏窗口的 1.025 ms/帧仅用于比较。若超出 33.3 ms/帧预算，先据分项数据减少重复构件或调离屏分辨率，再复拍细窗和池边。
